## Differential oracle (E-28)

The desktop differential compares the Kotlin extractor with the installed upstream tool on the same public URL. It runs only when explicitly enabled and never in default CI:

```sh
./gradlew :apps:desktop:test --tests "com.anydownlod.desktop.engine.YtDlpOracleTest" -PytDlpOracle=true
```

- Preconditions: `yt-dlp` on `PATH` at the pin `2026.08.19`. Without the property, or with any other version, the test is skipped and reports the version it found. The executable is started with an argument list, never a shell string; `ProcessBuilder` stays under `apps/desktop`. The oracle runs `yt-dlp -J --no-warnings --extractor-args "youtube:player_client=visionos" <url>` so both sides use the same innertube client.
- Compared fields: `id`, `title`, `channel_id`, `upload_date`, `age_limit`, `duration` (±1s), and the format set keyed by `format_id` with `ext`, `vcodec`, `acodec` (a missing codec equals `none`), `height`, `fps` (±0.001), and `protocol`. Ignored: URLs, `filesize`, `view_count`, thumbnails, and storyboard-only rows. The raw `-J` document contains signed media URLs, so it is parsed and discarded, never printed or stored.
- A divergence is a failure whose message lists field names and normalized values only; a `googlevideo` host in the diff fails the test explicitly.
- Allowed inputs live in `YtDlpOracleTest`: the public Big Buck Bunny URL plus its audio-only formats. Add cases there, not to CI.
- First run (2026-09-24) found real gaps in the T-060 translation: `isDrc`/`xtags` format-id suffixes (`-drc`, `-sr`) and the watch-page `uploadDate`/`familyFriendly` fallbacks. After fixing them the differential reports `27/27` formats and `0` diffs.

## How to use this matrix

1. Keep E-IDs stable. Add rows when upstream gains a capability the port must answer; mark rows Out with a reason rather than deleting them.
2. A task that ports a module updates `port/manifest.json` in the same change and regenerates the coverage block.
3. Statuses change only with linked evidence in the owning task. "Compiles" is not evidence; a harness or host test is.
4. The pin moves only at a phase boundary and is recorded in the ADR for that phase, the manifest, and every notice header the change touches.
